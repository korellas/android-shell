# Tilde for Windows

기존 Flutter 호스트 목록에서 SSH 터미널과 SFTP 파일 전송을 선택하는 Windows 실행 호스트입니다. 화면과 SSH 구현은 `flutter_ui`를 사용합니다.

터미널 상단의 기기 탭에서 연결 상태와 선택한 세션을 확인하고 전환하거나 개별 종료할 수 있습니다. 데스크톱에서는 보조키 줄을 표시하지 않으며 실제 키보드의 Tab과 단축키를 사용합니다.

`Ctrl+Tab`은 다음 탭, `Ctrl+Shift+Tab`은 이전 탭으로 순환합니다. 탭 전환 키는 원격 셸로 전송하지 않습니다.

배포 ZIP 전체를 풀고 `Tilde.exe`를 실행합니다. 함께 들어 있는 라이브러리와 `data` 폴더를 유지하세요. 실행에는 Flutter SDK가 필요하지 않습니다.

접속 설정은 Windows 사용자 데이터 폴더의 Tilde 디렉터리에 저장합니다. 저장한 비밀번호와 키 암호는 Windows 계정의 DPAPI로 보호합니다. 개인키 파일은 사용자가 선택한 원래 위치에서 읽으며 다른 기기의 키나 세션을 가져오지 않습니다.

SFTP 목록의 빈 공간이나 폴더 행에 탐색기의 파일·폴더를 놓으면 해당 원격 폴더에 업로드합니다. 원격 일반 파일은 다중 선택해 탐색기로 끌거나 복사하여 다운로드할 수 있습니다. 폴더 다운로드는 목록의 다운로드 기능에서 저장 폴더를 선택합니다. 탐색기에서 복사한 파일·폴더는 원격 목록에 붙여넣어 업로드합니다.

클릭으로 선택하고 Ctrl·Shift로 여러 항목을 고릅니다. 더블클릭이나 Enter로 폴더·미리보기를 엽니다. F2로 이름을 고치고, Delete로 삭제하며, Ctrl+C/X/V로 원격 항목을 복사·이동합니다. 단축키는 파일 목록에 포커스가 있을 때 적용합니다. 원격 복사는 임시 로컬 다운로드와 업로드를 거칩니다.

주소 입력, 경로 탐색, 뒤로·앞으로·상위 이동과 즐겨찾기를 제공합니다. 보기 및 정렬 사이드바에서 숨김 항목을 표시하고 검색·정렬합니다. 작은 화면에서는 설정 버튼으로 사이드바를 엽니다. 열 너비와 보기 설정, 서버별 즐겨찾기·최근 위치를 저장합니다.

전송은 작업 목록에서 진행량·속도·남은 시간을 확인하고 일시정지·취소·재시도할 수 있습니다. 다른 폴더를 탐색해도 작업 대상은 바뀌지 않습니다. 재시도는 완료된 항목을 제외하고 실패한 파일을 처음부터 전송합니다. 같은 이름의 파일은 덮어쓰기·건너뛰기·다른 이름을 선택하며, 폴더는 병합합니다. 탐색기로 내보낼 때 대상 충돌은 탐색기가 처리합니다.

새 파일과 텍스트 편집·서버 저장, 이미지 미리보기 및 권한 변경을 지원합니다. 미리보기 크기 제한은 파일 읽기 경로에서 검사합니다. 서버 파일이 편집 중 변경되면 덮어쓰기를 확인합니다.

파일·폴더의 더보기 메뉴 또는 마우스 오른쪽 버튼으로 이름 변경, 삭제와 정보를 열 수 있습니다. 상단의 새 폴더 버튼으로 현재 폴더에 디렉터리를 만듭니다. 이름 변경은 기존 항목을 덮어쓰지 않습니다. 폴더 삭제는 내용도 영구 삭제하며, 심볼릭 링크는 링크만 지웁니다. 삭제 취소는 남은 작업을 중단하며 이미 삭제한 항목은 복원하지 않습니다.

SSH의 AES-GCM 패킷 암복호화는 Windows CNG를 사용합니다. 암호 협상 순서와 서버 키 검증은 공통 SSH 구현을 따릅니다. Windows에서 실행하는 테스트는 CNG 표준 벡터와 패킷 위변조 거부를 검증합니다.

## 빌드와 검증

Windows 빌드는 `scripts/build-windows.ps1`의 `requiredFlutterVersion`에 지정된 SDK를 사용합니다. 이 버전에는 [Windows 한국어 IME 커서 수정](https://github.com/flutter/flutter/pull/186353)이 포함됩니다. Microsoft C++ Build Tools와 Windows SDK, Rust MSVC 도구 체인이 준비된 PowerShell에서 실행합니다.

```powershell
./scripts/build-windows.ps1
```

스크립트는 리소스 캐시를 지우고 분석·테스트·Windows release 빌드 후 필요한 Microsoft 런타임과 바로가기용 Tilde 아이콘을 함께 묶습니다. 생성물은 `artifacts/Tilde-Windows.zip`입니다.

Android 및 iPad 대상의 공통 소스 검증은 저장소 루트의 `scripts/build-flutter.sh` 지침을 따릅니다.
