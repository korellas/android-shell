# Tilde 디자인 구현 기준

사용자가 제공한 **Tilde 화면 가이드 v1 (2026-10-12)**을 제품 디자인의 기준으로 사용합니다. 오프라인 원본은 [tilde-screen-guide.html](tilde-screen-guide.html)에 보존합니다. 이 문서는 해당 원본의 설계 계약이며, 예시 서버·계정·버전·개수·날짜는 실제 사용자 데이터로 표시합니다.

## 브랜드와 공통 규칙

제품 표시명은 **Tilde**, 워드마크는 **tilde**, 설명은 **Tilde — SSH & Terminal**입니다. 심볼은 원본 SVG의 `~/` 곡선과 슬래시를 사용합니다. 런처·단색 아이콘·알림·시작 화면·도움말에 같은 브랜드를 적용합니다. 저작권과 ConnectBot 엔진의 출처 표시는 보존합니다.

앱과 터미널의 기본 테마는 Tilde Night/Day입니다. 원본의 tide·sand·coral 역할과 곡률을 따릅니다. 다른 터미널 테마를 선택하면 배경/전경에서 그룹·키·눌림·구분선의 표면을 계산하고 커서색을 강조색으로 사용합니다. Pretendard는 앱 본문, JetBrains Mono는 터미널 미리 보기와 주소·지문·코드에 사용합니다. 숫자·이름·키의 상태는 실제 엔진 값을 표시합니다.

설정은 즉시 적용합니다. 호스트·계정·키·프로필·포워딩 편집은 변경분을 모아 저장하고, 변경이 있을 때만 하단 저장 바를 표시합니다. 저장되지 않은 편집을 닫으면 변경 사항 버리기 시트를 표시합니다. 접속 취소·세션 종료·세션 ID 분리·한글 입력·스크롤의 기존 수정은 유지합니다.

휴대폰에서는 한 화면씩 이동하며, 펼친 화면에서는 설정/호스트 목록과 상세 화면을 나란히 표시합니다. 큰 글자에서도 조작과 값이 잘리지 않아야 합니다. 선택 항목은 tide 표면, 위험한 삭제는 coral, 권한이나 낮은 대비 안내는 sand로 구분합니다. 로딩 물결은 실제 대기 중에만 표시합니다.

## 플랫폼 동작의 표시

연결·알림의 `keepalive` 항목은 `FlutterShellActivity.applyWindowOptions`의 화면 켜짐 유지 기능을 정확히 표시합니다. 백그라운드 연결 알림은 Android 알림 설정으로 연결하고 실제 OS 권한 상태를 보여 줍니다. 샘플 문구 때문에 기존 화면 유지 기능을 네트워크 패킷 설정으로 오표시하거나, 시스템이 요구하는 연결 알림의 가짜 켜기/끄기를 만들지 않습니다.

## 데이터와 검증

제품명 변경 때문에 기존 호스트·키·설정 데이터가 별도 앱으로 갈라져서는 안 됩니다. 앱 ID, 엔진 채널과 저장소 식별자의 변경은 표시명 변경과 구분합니다. 검증 화면에 예시 데이터로 실제 기능을 대체하거나, 기존 기능의 경로를 없애지 않습니다.

원본의 각 화면을 구현 화면과 대조하고, 저장/취소·상속·조건부 필드·실패/권한 상태·검색·파일 선택·재정렬·키 관리의 관찰 가능한 동작을 검증합니다. Android와 iPad 대상은 `scripts/build-flutter.sh`로 함께 컴파일합니다. iPad 컴파일과 iOS 엔진 연결·서명·실기기 기능 검증은 별도로 기록합니다.
