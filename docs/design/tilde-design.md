# Tilde 디자인 구현 기준

사용자가 제공한 **Tilde 화면 가이드 v1 (2026-10-12)**을 제품 디자인의 기준으로 사용합니다. 오프라인 원본은 [tilde-screen-guide.html](tilde-screen-guide.html)에 보존합니다. 이 문서는 해당 원본의 설계 계약이며, 예시 서버·계정·버전·개수·날짜는 실제 사용자 데이터로 표시합니다.

원본 SHA-256: `eb10e993e645d14c8e9e961e9faf0ab76313ee88ba55389a4621d8b321a47ddb`.

## 브랜드와 공통 규칙

제품 표시명은 **Tilde**, 워드마크는 **tilde**, 설명은 **Tilde — SSH & Terminal**입니다. 심볼은 원본 SVG의 `~/` 곡선과 슬래시를 사용합니다. 런처·단색 아이콘·알림·시작 화면·도움말에 같은 브랜드를 적용합니다. 저작권과 ConnectBot 엔진의 출처 표시는 보존합니다.

시각 기준은 사용자가 승인한 [그래픽 가이드 v2 추가 기준](tilde-design-v2.md)을 우선합니다. [리파인 확정안](tilde-refine-v2.html)·[그래픽 가이드 v2](tilde-graphic-guide-v2.html)·[색 배합 검토](tilde-color-study.html)는 글꼴을 포함한 오프라인 원본입니다. v1의 화면별 기능·저장·인증 계약은 유지합니다.

앱과 터미널의 기본 테마는 Tilde Night/Day입니다. 원본의 tide·sand·coral 역할과 곡률을 따릅니다. 다른 터미널 테마를 선택하면 배경/전경에서 그룹·키·눌림·구분선의 표면을 계산하고 커서색을 강조색으로 사용합니다. Pretendard는 앱 본문, JetBrains Mono는 터미널 콘텐츠와 주소·지문·명령·키 조합·터미널 크기에 사용하고, 한글 UI 문구는 Pretendard로 표시합니다. 숫자·이름·키의 상태는 실제 엔진 값을 표시합니다.

설정은 즉시 적용합니다. 호스트·계정·키·프로필·포워딩 편집은 변경분을 모아 저장하고, 변경이 있을 때만 하단 저장 바를 표시합니다. 저장되지 않은 편집을 닫으면 변경 사항 버리기 시트를 표시합니다. 접속 취소·세션 종료·세션 ID 분리·한글 입력·스크롤의 기존 수정은 유지합니다.

휴대폰에서는 한 화면씩 이동하며, 펼친 화면에서는 설정/호스트 목록과 상세 화면을 나란히 표시합니다. 큰 글자에서도 조작과 값이 잘리지 않아야 합니다. 선택은 라디오 점 또는 세그먼트·칩의 표면으로 표시하며, 라디오 행 전체를 칠하지 않습니다. 섹션 제목과 숫자는 본문·보조색을 사용하고 위험한 삭제는 coral로 구분합니다. 시작 화면은 정적인 브랜드 심볼을 사용하고, 영역의 대기는 얇은 선형 진행 표시, 버튼과 단계의 대기는 작은 원형 진행 표시를 사용합니다. 런처의 컬러·단색 심볼은 같은 비율로 축소해 마스크 안의 여백을 확보합니다.

## 플랫폼 동작의 표시

연결·알림의 `keepalive` 항목은 `FlutterShellActivity.applyWindowOptions`의 화면 켜짐 유지 기능을 정확히 표시합니다. 백그라운드 연결 알림은 Android 알림 설정으로 연결하고 실제 OS 권한 상태를 보여 줍니다. 샘플 문구 때문에 기존 화면 유지 기능을 네트워크 패킷 설정으로 오표시하거나, 시스템이 요구하는 연결 알림의 가짜 켜기/끄기를 만들지 않습니다.

공통 터미널의 선택 동작은 `TerminalActions`의 단일 문맥 메뉴로 제공하며 선택한 텍스트의 복사·편집을 같은 위치에서 실행합니다. `TerminalKeyBar`의 `tab`은 스크롤 영역 밖 맨 오른쪽에 고정합니다. 인증 요청은 해당 콘솔 안에 표시하고 다른 세션으로 이동해도 응답 대상을 바꾸지 않습니다. 소프트 키보드와 시스템 바가 차지한 영역은 콘솔 레이아웃에서 한 번만 제외합니다. 공통 입력 뷰는 이미 처리된 시스템 여백을 렌더러에 다시 전달하지 않습니다. 제목 자동 숨김을 켜면 제목은 터미널 위에 겹쳐 표시하고, 나타나거나 사라질 때 행·열 크기를 바꾸거나 빈 제목 영역을 남기지 않습니다.

## 데이터와 검증

제품명 변경 때문에 기존 호스트·키·설정 데이터가 별도 앱으로 갈라져서는 안 됩니다. 앱 ID, 엔진 채널과 저장소 식별자의 변경은 표시명 변경과 구분합니다. 검증 화면에 예시 데이터로 실제 기능을 대체하거나, 기존 기능의 경로를 없애지 않습니다.

원본의 각 화면을 구현 화면과 대조하고, 저장/취소·상속·조건부 필드·실패/권한 상태·검색·파일 선택·재정렬·키 관리의 관찰 가능한 동작을 검증합니다. Android와 iPad 대상은 `scripts/build-flutter.sh`로 함께 컴파일합니다. iPad 컴파일과 iOS 엔진 연결·서명·실기기 기능 검증은 별도로 기록합니다.

| 14 프로필 | 그룹 목록의 왼쪽 작은 미리보기와 이름·테마·크기 요약 |

터미널에서 뒤로가기를 누르면 세션 유지·종료·취소를 선택합니다. 직접 연결 끊기는 즉시 세션을 정리하고 화면을 닫습니다. 알림의 연결 끊기는 앱을 열지 않고 모든 연결을 종료합니다. 빠른 종료 옵션과 자동 재연결의 기존 선택은 유지합니다. 호스트 삭제의 되돌리기는 같은 호스트 ID·포워딩 ID·자동 실행·신뢰한 서버 키·저장 비밀번호를 복구하며, 이미 끊긴 네트워크 연결을 다시 열지는 않습니다. 복구 데이터는 Android 내부 메모리에만 두고 Flutter에는 토큰만 전달합니다. ID나 이름이 새 데이터와 충돌하면 덮어쓰지 않고 실패를 알립니다. 되돌리기 안내가 닫히거나 Activity가 종료되면 임시 복구 데이터를 버립니다.

이 검수는 iOS 엔진 연결을 추가하지 않습니다. iPad unsigned 컴파일, 개발 서명, 설치, 실제 연결 검증은 각각 구분합니다.

후속 검수의 화면 렌더링 예시는 [홈](screenshots/review-home-day.png), [넓은 홈](screenshots/review-home-wide.png), [키보드](screenshots/review-keyboard-day.png), [터미널 설정](screenshots/review-terminal-day.png), [키 목록](screenshots/review-keys-night.png), [키 등록 실패](screenshots/review-enrollment-error.png), [큰 글자](screenshots/review-keys-large-text.png)에 기록합니다. 포함된 폰트와 예시 데이터를 사용한 Flutter 테스트 렌더링이며 실기기 캡처가 아닙니다. 네이티브 폰트 PNG와 콘솔의 실제 출력·IME는 별도로 검증합니다.

인증창은 연결이 열리기 전에도 현재 콘솔에서 표시합니다. 키 암호·생체인증·서버 키 확인·비밀번호 요청의 표시를 `isSessionOpen`으로 제한하지 않습니다. 터미널의 입력 뷰도 인증 대기 중 유지하며, 키 거절 후에는 서버가 제공한 다음 인증 방식의 요청을 같은 하단 인증창으로 전달합니다. 네이티브 터미널 배경과 IME·기능키 여백은 실제 세션 배경색을 사용합니다.

## v2 시각·반응형 계약

`tildeTheme`의 Night는 따뜻한 Graphite, Day는 Warm ink를 사용합니다. UI 색의 역할은 Tide(주 동작·선택·연결), Sand(새 출력·주의), Coral(오류·삭제)로 한정합니다. 호스트 색과 터미널 ANSI 색은 콘텐츠이며 상태색으로 해석하지 않습니다. 사용자 지정 터미널 테마는 배경·전경의 기존 표면 mix를 유지하고 구분선 mix만 v2 기준으로 높입니다. 색과 치수의 정본은 추가 기준과 해당 구현 토큰입니다.

설정 첫 화면은 카테고리 타일과 짧은 요약을 표시합니다. 화면 설정의 앱 테마는 아이콘 세그먼트, 폰트 관리는 글꼴 선택 안에서 엽니다. 하드웨어 키보드는 하위 화면으로 접고, 가로 제스처는 끔·세션·tmux 창 중 하나만 선택합니다. 실제 엔진의 저장 값과 기존 하드웨어 옵션은 보존합니다.

목록·상세 분기는 720dp, 시트 분기는 840dp입니다. 설정과 홈의 넓은 목록은 상세와 나란히 놓고 상세 최대 폭은 640dp로 제한합니다. 휴대폰 시트는 `showTildeSheet`로 열며, 넓은 화면은 가운데 대화상자로 전환합니다. 콘솔 메뉴는 넓은 화면에서 오른쪽 사이드 시트로 열고 터미널을 계속 사용할 수 있습니다. 토스트는 넓은 화면의 왼쪽 아래, 저장 바는 오른쪽 아래에 제한된 폭으로 표시합니다. 큰 글자에서는 설정 타일과 내용의 열 수를 줄입니다.

콘솔 상단은 가로 스크롤 세션 탭, 메뉴는 ⋯로 표시합니다. 모드 문구는 고정하고 스위치로 상태를 표현합니다. 나가기 시트는 대상 세션과 연결 유지·세션 종료를 표시하며, 바깥 영역이나 뒤로 가기로 취소할 수 있습니다. 편집 후 전송은 대상 세션 이름과 전송 버튼을 표시합니다. 제목·배너·진행 상태에 따른 기존 터미널 크기 유지와 세션 ID 분리 계약은 그대로 적용합니다.

[v2 홈 · Day](screenshots/v2-home-day.png), [넓은 홈](screenshots/v2-home-wide.png), [호스트 메뉴](screenshots/v2-host-menu-day.png), [설정 · Day](screenshots/v2-settings-day.png), [넓은 설정](screenshots/v2-settings-wide.png), [키보드](screenshots/v2-keyboard-day.png), [제스처](screenshots/v2-gesture-night.png), [콘솔 사이드 메뉴](screenshots/v2-console-side-menu.png), [큰 글자 메뉴](screenshots/v2-host-menu-large-text.png)는 `tilde_v2_test.dart`의 포함된 폰트와 픽스처를 사용한 렌더링입니다. 콘솔은 공통 Dart 터미널에 넣은 예시 출력을 캡처하며, 폰트 미리보기 채널에 이미지 응답이 없는 상태를 포함합니다. `TILDE_V2_SCREENSHOTS`를 켜면 해당 테스트에서 이미지를 다시 생성합니다.

특수키 편집은 기존 순서·숨김·높이·Fn 그룹 설정을 그대로 저장합니다. 키캡을 길게 끌어 순서를 바꾸고, 탭하거나 숨긴 영역으로 끌어 숨깁니다. 숨긴 키캡은 탭해 복원하며 터미널과 실제 순서의 바 미리보기는 상세 영역 아래에 고정합니다. [키캡 편집](screenshots/v2-keybar-editor.png)과 [넓은 키캡 편집](screenshots/v2-keybar-editor-wide.png)도 같은 테스트 픽스처의 렌더링입니다.

입력창은 일반·포커스·검증 오류 상태에서 같은 모서리 규칙을 유지합니다. 오류와 도움말은 필요한 줄로 펼치고, 큰 글자에서 나란한 필드·라벨과 값이 잘리면 세로 배치로 전환합니다. 특수키의 실제 바와 미리보기는 글자를 맞추려고 전체를 축소하지 않으며, 고정 키와 가운데 스크롤 영역의 역할을 유지합니다. 큰 화면의 시트 내용도 대화상자 모서리 안에서 그립니다.
